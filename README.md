# 🧠 K-Means Initialization Methods — MMI Lab

This repository contains the implementation and analysis of K-Means clustering algorithms with different initialization strategies as part of the African Institute for Mathematical Sciences (AIMS) — Master in Machine Intelligence (MMI) Lab assignment.

## 📌 Project Description

The goal is to explore and compare different initialization methods for the K-Means clustering algorithm and assess their impact on performance and convergence.

### Tasks Completed:
- ✅ Basic K-Means with random initialization
- ✅ K-Means++ smart initialization
- ✅ Max-Distance Seeding (custom method)
- ✅ Elbow Method to estimate optimal number of clusters
- ✅ Evaluation of convergence speed and clustering results
